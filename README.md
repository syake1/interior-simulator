# ネットインテリア月島 Webサイト

HTML / CSS / JavaScriptによる9ページの静的サイトです。Wix版とは別の、Codexで直接編集できるサイトです。公開先でNode.jsやデータベースを動かす必要はありません。

## ローカル確認

今回の確認用サーバーは http://127.0.0.1:8790/ で起動済みです。2026年10月5日、9ページを375px・1440pxで検査し、トップは320px・390px・768px・1920pxでも確認しました。ローカルフォントの読み込み、リンク、画像、見出し、メール宛先、メニュー、FAQ、メール文面作成の検査でエラーはありません。実際のメール送信・受信は未確認です。

`index.html`をブラウザで開くと閲覧できます。コピー機能なども確認する場合は、Node.jsを利用してこのフォルダで次を実行してください。

```powershell
npm run preview
```

URL: http://127.0.0.1:8788 。ポートが使用中の場合は `$env:PORT='8789'` を設定して起動します。停止はCtrl+Cです。

## 編集・再生成

各HTMLは `scripts/build.mjs` から生成しています。本文や共通ヘッダーの編集はこのファイルを変更し、次を実行します。

```powershell
npm run build
```

共通レイアウト: `assets/styles.css`、鮮やかな配色・トップのデザイン: `assets/vivid-theme.css`、メニュー・フォーム等の動作: `assets/site.js`。

## メールアドレス・対応市町村

`assets/site-config.js` の `email` を変更してください。メールボタンとフォームの宛先はこの設定を読み込みます。HTML内のJavaScript無効時のメールリンク・構造化データにも反映するため、変更後に `npm run build` を実行してください。

市町村は同ファイルの `areas` に追加できます。例えば `'石川県': ['金沢市', '小松市']`。対応できる地域のみ掲載してください。変更後に再生成してください。

## 写真の差し替え

画像は `images/` に分離しています。WebP画像を同じファイル名で置き換えると、掲載箇所すべてに反映されます。横長3:2を推奨し、ヒーロー1536×1024、その他960×640を目安にします。生成元PNGはCodexの生成画像フォルダにあります。通常の差し替えに画像生成ツールや画像最適化スクリプトは不要です。

| 画像 | 主な使用場所 |
| --- | --- |
| hero.webp | トップ大写真、壁紙ページの室内写真 |
| craft.webp | トップ紹介、壁紙の施工説明、小規模補修ページ |
| floor.webp | クッションフロア紹介、床工事ページ |
| tile.webp | フロアタイル紹介、床工事ページ |
| window.webp | 窓まわり紹介、窓まわりページ |
| before.webp | Beforeイメージ |
| after.webp | Afterイメージ、壁紙紹介、壁紙ページ |

現在の7枚は内蔵imagegenツールで生成したAIイメージです。実際の施工実績ではありません。BeforeとAfterも別々に生成された画像です。実際の写真へ差し替える場合は、画像の使用許可・施主様の公開許可をご確認のうえ、本文のイメージ表記とaltを適切に編集してください。

生成プロンプトの概要: 明るい日本の住宅リビング／クロスを押さえる職人の手元／石目CFの洗面所／木目フロアタイルのダイニング／カーテン・ブラインド・ロールスクリーンの窓辺／貼り替え前の軽い汚れがある空室／貼り替え後の白とグレーのクロスの空室。いずれも自然光、実写風、文字・ロゴなし。

## 実際の施工事例の追加

`content/works.json` に次のように追加してください。施工写真を `images/works/` に保存し、`npm run build` でトップと施工事例ページに反映します。実際の事例を追加すると、仮のBefore/Afterは掲載されなくなります。

```json
[
  {
    "title": "公開許可を得た実際の工事名",
    "area": "実際の施工地域",
    "service": "壁紙（クロス）貼り替え",
    "before": "images/works/case-01-before.webp",
    "after": "images/works/case-01-after.webp",
    "description": "実際に行った施工の範囲や内容",
    "publication": {
      "approved": false,
      "anonymized": false,
      "rightsConfirmed": false
    }
  }
]
```

## 実績表記・権利保護

上の施工事例テンプレートは、許諾・匿名化・権利確認を行った項目だけ `publication` の各値を `true` にします。3項目がすべて `true` になった事例のみ生成されます。確認していない事例を公開するためにフラグを変更しないでください。

### 表記と権利の扱い

実績表記と画像の編集ルールは `AGENTS.md` に保存しています。実名の施設・店舗・ホテル・元請会社は原則として地域と用途・業種で表し、個人施主の氏名や詳細住所は掲載しません。業界区分や工事規模は、確認できた事実のみを使用します。

写真の表札・看板・顔・車両番号・郵便物、EXIF、altやキャプションにも識別情報を残さないよう確認してください。第三者のロゴ・公式写真等は無断で使用しません。実名掲載を求められた場合も、関係先の許諾・契約・NDA等を確認してから判断します。

`images/` は公開されるフォルダです。ページに表示しない事例の写真も直接URLでアクセスされる可能性があるため、未確認の写真や秘密情報を置かないでください。許諾の記録・元の個人情報・原本写真はサイトの公開フォルダに含めません。

## 住宅改修の補助制度ページ

`subsidies.html` は制度の対象例、内装工事として相談できる範囲、事前申請の注意点、国・県の公式案内を紹介しています。国・県の参照先は2026年10月4日に確認しました。金額・受付中の断定・利用保証は掲載していません。制度紹介は `scripts/subsidies-page.mjs`、参照先と市町村別一覧は `content/subsidies.json` で管理します。

市町村別の制度一覧は初期状態では空です。`municipalityPrograms` に、次の形式で確認できた制度を追加できます。未完成の項目は `published: false` のままにしてください。

```json
{
  "prefecture": "石川県",
  "municipality": "",
  "name": "",
  "category": "",
  "overview": "",
  "conditions": "",
  "applicationTiming": "",
  "officialUrl": "",
  "checkedAt": "2026-10-04",
  "published": false
}
```

県名は石川県または福井県、市町村名・正式な制度名・概要・対象条件・申請時期・公式URL・確認日は必須です。国や自治体の公式HTTPS URL（go.jp / lg.jp）を使用します。内容を確認して `published: true` にし、`npm run build` で県別一覧に反映します。年度・予算・受付状況・施工業者の要件などを都度確認し、公式案内へ誘導してください。制度の対象工事と当店の対応工事を混同させないようにします。

## メール相談フォーム

フォームはメール作成補助です。入力を確認してメール文面を作成し、メールアプリから利用者自身が送信します。サーバーからメールを送信する機能や受付完了通知はありません。入力内容をサーバーへ保存せず、外部送信サービスも使っていません。メールアプリがない環境では文面をコピーし、Webメールに貼り付けて送信できます。

メールの実送信テストは行っていません。公開前に実際の受付メールへ変更し、受信・返信ができることを確認してください。現在の `example@example.com` は仮設定です。

## 横に流れる施工経験

トップページの「クロス貼り工事経験箇所」は `content/experience.json` で管理します。
店名・メニュー直下の高さ約44pxのグレー帯に、白文字でゆっくり横へ流します。
企業名や施設名を出さず、ユーザーが提供した社数・工事種別を掲載しています。
追加・変更後はビルドと表示用フォントの再生成を行います。
一時停止ボタン、マウスを重ねた際の停止、動きを抑える端末設定に対応しています。

## フォントの追加

保管場所は `assets/fonts/` です。書体別にフォント本体とライセンス文書を保存します。
追加手順は `assets/fonts/README.md`、全ページ共通の読み込み・使い分け設定は `assets/fonts.css` にあります。
Noto Sans JP・Noto Serif JP・Zen Maru Gothic Regularの本体とライセンスを同梱し、CSSに登録済みです。
本文はゴシック、店名と大見出しは明朝、職人直営の強調文は丸ゴシックを使用しています。
表示用は軽量化した `web.woff2` で、元TTFは保管用です。`fonts.css` の書体変数で変更できます。
新しい文字を追加した際の表示用フォント再生成は `assets/fonts/README.md` を参照してください。
公開時はフォントのライセンスを同梱し、保管用TTFと `.tools/` はアップロード不要です。

## 公開手順

1. `assets/site-config.js` に実際のメールアドレスを設定します。
2. 内容・対応地域・写真の表記を確認します。
3. 公開URLを設定して再生成します。

```powershell
$env:SITE_URL='https://実際のドメイン'
npm run build
```

公開URLを設定するとcanonical、OGP画像、sitemap.xml、robots.txtのサイトマップ指定を生成します。ドメインが未定の状態では架空のURLを出力しません。

4. 9個のHTMLと `assets/`、`images/`、`robots.txt`、生成された `sitemap.xml` をレンタルサーバー等の公開フォルダ（public_htmlなど）へアップロードします。`scripts/`、`content/`、`qa/`、READMEは公開不要です。
5. ドメインとSSLを設定し、HTTPSで9ページ・画像・メールリンク・フォームを実機で確認します。
6. Google Search Consoleへサイトを登録し、sitemap.xmlを送信します。検索順位や検索結果での表示を保証するものではありません。

会社の所在地・営業時間・実績・電話番号は提供されていないため創作していません。必要な公開情報は実際の内容を確認して追加してください。
